# Підготовка до вступного іспиту Ph.D. — Комп'ютерні науки (СумДУ)

Цей локальний вебдодаток призначений для підготовки до вступного випробування в аспірантуру за спеціальністю **F3 «Комп'ютерні науки»**.

## Структура проекту
- `index.html` — Головна сторінка інтерактивного тестувальника.
- `styles.css` — Стилі оформлення, фіксована шапка (Sticky Header), адаптивний дизайн.
- `script.js` — Логіка проведення тесту, розрахунку балів, таймера та перевірки.
- `questions.js` / `questions.json` — Файли з масивом із 30 тестових питань з 10 розділів програми.
- `README.md` — Інструкція з використання.

## Як запустити локально
1. Завантажте та розпакуйте ZIP-архів у довільну папку на вашому комп'ютері.
2. Подвійним кліком відкрийте файл `index.html` у будь-якому сучасному веббраузері (Chrome, Firefox, Edge, Safari).
3. Тест повністю автономний і не потребує вебсервера або підключення до Інтернету!

## Особливості використання:
- **Перевірка після натискання**: Вибирайте варіанти відповідей у зручному темпі. Правильні відповіді та роз'яснення відобразяться лише після натискання кнопки **«Перевірити тест»** у верхній закріпленій панелі.
- **Оцінювання за формулою СумДУ**: Під час перевірки вираховується підсумкова оцінка за шкалою 100–200 балів та оцінюється досягнення мінімального порогу (17%).
- **Редактор JSON**: Кнопка **«Редактор JSON»** дозволяє завантажувати власні набори питань, вивантажувати поточний набір у файл `.json` або змінювати текст питань прямо у браузері.
